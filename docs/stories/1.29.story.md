# Story 1.29 — Configurações globais do servidor (admin)

## Status: Done

## Story
Como administrador, quero controlar configurações globais do servidor que afetam o comportamento de todos os usuários não-admin, para poder restringir ou liberar funcionalidades conforme necessário.

## Acceptance Criteria
- [x] Configuração "Permitir criação de salas": quando desativada, não-admins recebem 403 ao tentar criar salas
- [x] Configuração "Modo suporte" (`admin_only_chat`): quando ativado, não-admins só podem acessar a sala Geral (redirecionados se tentarem acessar outra sala) e não podem criar salas
- [x] API GET `/api/auth/admin/settings` — retorna configurações atuais (apenas admin)
- [x] API POST `/api/auth/admin/settings` — salva configurações (apenas admin)
- [x] Configurações persistidas no banco de dados (`global_settings` table)
- [x] Valores padrão: `allow_room_creation = '1'`, `admin_only_chat = '0'`
- [x] Aba "Configurações" no dashboard admin com toggles visuais

## Tasks
- [x] Tabela `global_settings (key TEXT PRIMARY KEY, value TEXT NOT NULL)` em `db.ts`
- [x] Helpers `getSetting(key)` e `setSetting(key, value)` em `db.ts`
- [x] Seed de valores padrão no startup
- [x] API `/api/auth/admin/settings` (GET + POST)
- [x] Enforçar `allow_room_creation` em `src/app/api/rooms/route.ts`
- [x] Enforçar `admin_only_chat` em `src/app/chat/[roomId]/page.tsx` (redirect para `/chat/general`)
- [x] Aba "Configurações" em `src/app/admin/page.tsx` com toggles

## Dev Notes
- `global_settings` usa `INSERT OR REPLACE` para upsert — simples e idiomático para SQLite
- Seed usa `INSERT OR IGNORE` para não sobrescrever valores já configurados pelo admin
- `admin_only_chat` redireciona server-side (no page.tsx), portanto não depende de JS no client
- Apenas as chaves em `ALLOWED_KEYS` são aceitas no POST para evitar injeção de chaves arbitrárias

### Notes

- Admins são isentos de ambas as restrições via `if (!session.isAdmin)` antes dos guards.
