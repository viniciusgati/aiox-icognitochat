## Descrição

Como usuário mobile, quero instalar o IcognitoChat na tela inicial do meu celular a partir do browser (sem app store), para que eu possa abrir rapidamente como um app nativo.

---

## Critérios de Aceitação

- [ ] `manifest.json` configurado com: nome, ícone 192x192, ícone 512x512, `display: standalone`, `theme_color`, `background_color`
- [ ] next-pwa gera service worker funcional
- [ ] Chrome/Android exibe banner "Adicionar à tela inicial"
- [ ] Safari/iOS permite "Add to Home Screen" via menu compartilhar
- [ ] App abre em modo standalone (sem barra de endereços)
- [ ] Interface mobile responsiva: chat ocupa tela inteira, teclado não quebra layout
- [ ] Touch scrolling suave na lista de mensagens
- [ ] Input de mensagem fixo no rodapé (não some com teclado virtual)
