# Story 1.13 — Expiração Automática de Sessão

**Status:** Ready for Review
**Epic:** 1 — IcognitoChat MVP
**Story:** 1.13
**Depende de:** 1.2

---

## Descrição

Como usuário, quero que minha sessão expire automaticamente após um período de inatividade, para que minha conta esteja protegida caso esqueça de sair em um dispositivo compartilhado.

---

## Contexto Técnico

A sessão atual via `iron-session` é criada no login mas não tem TTL explícito configurado. O cookie persiste indefinidamente. Com o banco persistindo via Railway Volume, sessões antigas podem ser reutilizadas por tempo indeterminado.

Duas camadas de expiração:
1. **Cookie TTL:** `iron-session` suporta `ttl` em segundos — define quando o cookie expira no browser
2. **Inatividade no servidor:** verificar `last_seen_at` do usuário no banco; se > threshold, invalidar sessão

Valor sugerido: 7 dias de TTL absoluto + 24h de inatividade.

---

## Critérios de Aceitação

- [ ] Sessão tem TTL de 7 dias configurado no `iron-session` (cookie expira no browser)
- [ ] Middleware verifica `last_seen_at` do usuário — se > 24h sem atividade, redireciona para login
- [ ] Campo `last_seen_at` na tabela `users` é atualizado a cada request autenticado
- [ ] Usuário vê mensagem "Sessão expirada, faça login novamente" ao ser redirecionado
- [ ] Configuração de TTL via variáveis de ambiente `SESSION_TTL_DAYS` e `SESSION_INACTIVE_HOURS` (com defaults)
