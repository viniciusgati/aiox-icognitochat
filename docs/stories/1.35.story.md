# Story 1.35 — Detecção de Compartilhamento de Tela + Kick Automático

## Status: Ready for Dev

## Story
Como administrador, quero que o sistema detecte quando um usuário está compartilhando a tela via browser e automaticamente encerre sua sessão e apague as mensagens da sala, para proteger o conteúdo confidencial do chat de vazamentos via screen sharing.

## Contexto Técnico
A detecção usa a **Page Visibility API** + **`document.onvisibilitychange`** combinada com o monitoramento de **`navigator.mediaDevices`** para identificar quando o conteúdo do browser está sendo capturado/compartilhado via tab capture ou screen share iniciado pelo browser.

Adicionalmente, aplica um **CSS anti-capture trick**: ao detectar screen sharing ativo, o conteúdo sensível fica preto/invisível na captura enquanto permanece visível para o usuário local (usando `mix-blend-mode` + `color-scheme` em um overlay).

Importante: **não detecta** OBS, gravadores nativos do OS ou screenshots de botão físico — apenas screen share iniciado pelo browser (Meet, Teams, Discord, etc.).

## Acceptance Criteria

### Detecção de Screen Share
- [ ] Ao detectar que a aba está sendo capturada via browser, exibir banner de aviso imediato
- [ ] Banner: "⚠️ Compartilhamento de tela detectado. Sua sessão será encerrada."
- [ ] Após 3 segundos do aviso, emitir evento de kick via Socket.IO ao servidor
- [ ] Servidor processa o kick: encerra a sessão do usuário e emite `room:user-kicked` para a sala

### Kick e Limpeza
- [ ] Usuário kickado é desconectado e redirecionado para `/`
- [ ] Se a sala for efêmera (`is_ephemeral = 1`), todas as mensagens da sala são deletadas do DB no kick
- [ ] Se a sala não for efêmera, apenas o usuário é desconectado (mensagens preservadas)
- [ ] Os outros participantes da sala recebem notificação: "Um usuário foi removido por compartilhamento de tela"

### CSS Anti-Capture Overlay
- [ ] Quando screen share é detectado, aplicar classe CSS `screen-sharing-active` no `<body>`
- [ ] Com essa classe, o conteúdo do chat fica invisível na captura (preto) mas visível localmente
- [ ] Implementar via CSS: `@media (display-mode: browser)` + `mix-blend-mode` trick

### Hook de Detecção (`use-screen-capture-detection`)
- [ ] Hook client-side que monitora estado de screen sharing
- [ ] Retorna `{ isBeingCaptured: boolean, detectionMethod: string }`
- [ ] Usa `document.visibilityState` + verificação de `mediaDevices` state
- [ ] Sem falsos positivos por simples troca de aba (requer padrão específico de captura)

### Limitações Documentadas
- [ ] Exibir na UI (tooltip ou info): "Protege contra compartilhamento via browser. Não detecta gravadores nativos do OS."

### CSS Anti-Capture Trick
```css
/* Funciona no Chrome/Edge para tab capture */
.screen-sharing-active .chat-messages {
  /* Força o conteúdo a aparecer preto em capturas de tela do browser */
  filter: brightness(0);
  /* Alternativa: */
  mix-blend-mode: difference;
}
```

### Socket.IO Events (novo)
- `client → server`: `screen:sharing-detected` `{ roomId, username }`
- `server → room`: `user:kicked` `{ username, reason: 'screen-sharing' }`
- `server → kicked user`: `session:terminated` `{ reason: 'screen-sharing' }`

### API Route (novo)
- `POST /api/rooms/[roomId]/kick` — server-side: desconectar usuário + deletar mensagens se ephemeral
