# Story 1.9 — Controle da Sala pelo Criador (Kick & Close)

**Status:** Ready for Review
**Epic:** 1 — IcognitoChat MVP
**Story:** 1.9
**Depende de:** 1.7

---

## Descrição

Como criador de uma sala efêmera, quero poder remover participantes indesejados (kick) e encerrar a sala manualmente — apagando tudo e desconectando todos os presentes — para ter controle total sobre o espaço que criei.

---

## Contexto Técnico

Atualmente o servidor (`server.ts`) rastreia `roomUsers: Map<string, Map<socketId, username>>` mas não guarda quem criou a sala. O criador precisa ser identificado para ter autoridade sobre kick e close.

A sala efêmera já é criada por um usuário autenticado (sessão via iron-session). O `socket join-room` recebe `username` — esse username do primeiro a entrar na sala e criar a sessão socket precisa ser associado como "owner".

Alternativa mais simples e robusta: guardar `roomOwner: Map<roomId, socketId>` no servidor no momento do `join-room` quando a sala ainda não tem owner registrado (ou seja, primeiro a entrar).

---

## Critérios de Aceitação

- [x] O primeiro usuário a entrar numa sala efêmera é definido automaticamente como owner
- [x] Apenas o owner vê controles de administração: botão "Fechar Sala" e botão de kick ao lado de cada participante
- [x] Ao clicar em kick em um participante, esse usuário recebe evento `kicked` e é redirecionado para `/chat` com mensagem "Você foi removido da sala"
- [x] O owner não pode se kickar (seu próprio nome não exibe botão de kick)
- [x] Ao clicar em "Fechar Sala", o owner confirma a ação (dialog nativo), e então:
  - Todos os participantes recebem evento `room-closed` e são redirecionados para `/chat` com mensagem "A sala foi encerrada pelo criador"
  - A sala é deletada do banco de dados imediatamente (não aguarda todos saírem)
  - O owner também é redirecionado
- [x] Os controles de kick e close aparecem somente em salas efêmeras (salas persistentes não têm esse controle)
- [x] Se o owner sair antes de fechar, o próximo usuário presente torna-se o novo owner
- [x] A lista de participantes visível ao owner mostra o username de cada um com o botão de kick

## Notas de Implementação

```typescript
// server.ts — estruturas adicionais
const roomOwners = new Map<string, string>() // roomId → socketId

// join-room: definir owner
if (!roomOwners.has(roomId)) {
  roomOwners.set(roomId, socket.id)
  socket.emit('room-owner', true)
}

// emitir lista de usernames além do count
const usersList = Array.from(roomUsers.get(roomId)?.values() ?? [])
io.to(roomId).emit('room-users-list', usersList)

// kick-user
socket.on('kick-user', ({ roomId, targetUsername }) => {
  if (roomOwners.get(roomId) !== socket.id) return // não autorizado
  const users = roomUsers.get(roomId)
  const targetSocketId = [...(users?.entries() ?? [])].find(([, u]) => u === targetUsername)?.[0]
  if (targetSocketId) {
    io.to(targetSocketId).emit('kicked')
    io.sockets.sockets.get(targetSocketId)?.leave(roomId)
    users?.delete(targetSocketId)
    io.to(roomId).emit('room-users', users?.size ?? 0)
    io.to(roomId).emit('room-users-list', Array.from(users?.values() ?? []))
  }
})

// close-room
socket.on('close-room', ({ roomId }) => {
  if (roomOwners.get(roomId) !== socket.id) return
  io.to(roomId).emit('room-closed')
  deleteRoom(roomId)
  roomUsers.delete(roomId)
  roomOwners.delete(roomId)
  ephemeralRooms.delete(roomId)
})

// promoção de owner ao desconectar
function promoteNewOwner(roomId: string, oldSocketId: string) {
  if (roomOwners.get(roomId) !== oldSocketId) return
  roomOwners.delete(roomId)
  const nextSocketId = roomUsers.get(roomId)?.keys().next().value
  if (nextSocketId) {
    roomOwners.set(roomId, nextSocketId)
    io.to(nextSocketId).emit('room-owner', true)
  }
}
```
