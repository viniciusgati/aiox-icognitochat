# Story 1.16 — TTL de Mensagens (Limpeza Periódica)

**Status:** Ready for Review
**Epic:** 1 — IcognitoChat MVP
**Story:** 1.16
**Depende de:** 1.4, 1.10

---

## Descrição

Como usuário preocupado com privacidade, quero que mensagens antigas sejam automaticamente apagadas do servidor após um período configurável, para que o histórico de chat não fique armazenado indefinidamente.

---

## Contexto Técnico

Mensagens são salvas na tabela `messages` do SQLite mas nunca são deletadas (nem no shutdown com Railway Volume). Para um chat "incógnito", acumular histórico permanente é inconsistente com a proposta do produto.

Solução: job periódico (interval no servidor) que deleta mensagens com `created_at` anterior ao threshold. Default: 24 horas. Configurável via env `MESSAGE_TTL_HOURS`.

Nota: mensagens de salas efêmeras já são apagadas em cascata quando a sala é deletada (`ON DELETE CASCADE`). O TTL afeta principalmente salas permanentes (ex: sala "Geral").

---

## Critérios de Aceitação

- [ ] Mensagens com `created_at` anterior a `MESSAGE_TTL_HOURS` (default: 24h) são deletadas automaticamente
- [ ] Limpeza executa a cada hora (interval no servidor)
- [ ] Limpeza também executa no startup do servidor
- [ ] Log informativo: `[Server] TTL cleanup: deleted N messages older than Xh`
- [ ] Configurável via `MESSAGE_TTL_HOURS` no `.env` (0 = desabilitado)
- [ ] Salas efêmeras não são afetadas (já têm cascade delete)
