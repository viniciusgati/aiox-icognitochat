# Story 1.25 — Mensagem autodestrutiva por sala (TTL configurável)

## Status: InProgress

## Story
Como usuário criando uma sala, quero definir um TTL para as mensagens, para que elas desapareçam automaticamente após o tempo configurado.

## Acceptance Criteria
- [ ] Campo TTL no modal de criação (off, 30s, 1m, 5m, 10m, 30m, 1h) — disponível para salas normais e rápidas
- [ ] TTL salvo na coluna `message_ttl_seconds` da tabela `rooms`
- [ ] Mensagens removidas do estado React após TTL (calculado a partir do `timestamp` da mensagem, não da recepção)
- [ ] Mensagens cujo TTL já expirou no momento da recepção são descartadas sem exibição
- [ ] Banner no ChatWindow indicando o TTL ativo da sala
- [ ] Próprias mensagens também desaparecem

## Tasks
- [ ] Migração DB: `ALTER TABLE rooms ADD COLUMN message_ttl_seconds INTEGER`
- [ ] API POST /api/rooms aceita `messageTtlSeconds` e salva no DB
- [ ] CreateRoomModal: dropdown de TTL
- [ ] page.tsx: lê `message_ttl_seconds` e passa como prop ao ChatWindow
- [ ] ChatWindow: recebe prop, exibe banner, passa ao useSocket
- [ ] useSocket: agenda remoção por timeout após cada mensagem recebida/enviada
