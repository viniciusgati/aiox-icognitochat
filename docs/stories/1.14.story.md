# Story 1.14 — Limpeza de Salas Efêmeras Órfãs no Startup

**Status:** Ready for Review
**Epic:** 1 — IcognitoChat MVP
**Story:** 1.14
**Depende de:** 1.7, 1.10

---

## Descrição

Como administrador, quero que salas efêmeras sem participantes sejam automaticamente removidas quando o servidor inicia, para que o banco não acumule salas mortas de deploys/crashes anteriores.

---

## Contexto Técnico

Salas efêmeras são criadas com `is_ephemeral = 1` no banco. A limpeza ocorre via `handleRoomEmpty()` no `server.ts` quando o último usuário sai. Porém, se o servidor cair/reiniciar com salas efêmeras ativas, essas salas ficam no banco permanentemente — ninguém está conectado para disparar a limpeza.

Com Railway Volume preservando o banco entre deploys, esse acúmulo se torna progressivo.

Solução: no startup do servidor, deletar todas as salas `is_ephemeral = 1` do banco, pois por definição não há ninguém conectado quando o servidor acabou de iniciar.

---

## Critérios de Aceitação

- [ ] Ao iniciar o servidor, todas as salas com `is_ephemeral = 1` são deletadas do banco automaticamente
- [ ] A limpeza ocorre ANTES do servidor começar a aceitar conexões
- [ ] Log informativo no startup: `[Server] Cleaned N orphaned ephemeral rooms`
- [ ] Se não há salas órfãs, log ainda aparece com `N = 0`
- [ ] Salas permanentes (`is_ephemeral = 0`) NÃO são afetadas
