# Story 1.21 — Reply/Quote de Mensagem

**Status:** Ready for Dev
**Epic:** 1 — IcognitoChat MVP
**Story:** 1.21
**Depende de:** 1.4

---

## Descrição

Como usuário, quero clicar em uma mensagem para responder a ela com citação, para que o contexto da conversa fique claro em mensagens paralelas.

---

## Critérios de Aceitação

- [ ] Clicar em uma mensagem abre um preview de "respondendo a" acima do input
- [ ] A mensagem enviada carrega `replyTo: { id, username, content }` no payload
- [ ] O MessageBubble exibe a citação acima do conteúdo quando `replyTo` presente
- [ ] Botão ✕ no preview cancela o reply
- [ ] Funciona com mensagens próprias e de outros
- [ ] Content truncado em 80 chars no preview

---

## Tarefas

- [ ] Atualizar `Message` interface em `socket-client.ts` com `replyTo?`
- [ ] Atualizar `sendMessage` para aceitar e passar `replyTo`
- [ ] Atualizar `server.ts` para relay do campo `replyTo` no evento `receive-message`
- [ ] Atualizar `MessageBubble.tsx` para exibir citação
- [ ] Atualizar `ChatWindow.tsx` com estado `replyingTo` e preview bar
