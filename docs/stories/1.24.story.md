# Story 1.24 — Limite de Participantes por Sala Efêmera

**Status:** Ready for Dev
**Epic:** 1 — IcognitoChat MVP
**Story:** 1.24
**Depende de:** 1.7, 1.9

---

## Descrição

Como criador de uma sala efêmera, quero definir um número máximo de participantes ao criar a sala, para controlar quem pode entrar.

---

## Critérios de Aceitação

- [ ] Ao criar sala efêmera, campo opcional "Máx. participantes" (2-20, default sem limite)
- [ ] Server armazena `maxParticipants` em memória por roomId
- [ ] Se sala lotada, novo participante recebe evento `join-denied` e vê mensagem "Sala lotada"
- [ ] Criador não é impedido de entrar (sempre permitido)
- [ ] Sem limite configurado = comportamento atual (ilimitado)

---

## Tarefas

- [ ] Adicionar `maxParticipants?: number` ao payload `join-room` no `server.ts`
- [ ] Armazenar `roomMaxParticipants: Map<string, number>` no `server.ts`
- [ ] Verificar limite no `join-room` antes de adicionar ao room
- [ ] Emitir `join-denied` ao socket tentando entrar em sala lotada
- [ ] Adicionar listener `join-denied` em `socket-client.ts` com callback `onJoinDenied`
- [ ] Atualizar `RoomList.tsx` com input de max participantes ao criar sala efêmera
- [ ] Passar `maxParticipants` no `join-room` emit do `socket-client.ts`
