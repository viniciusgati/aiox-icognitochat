# Story 1.31 — Redesign Visual: Dark Mode Moderno

## Status: Ready for Review

## Story
Como usuário, quero uma interface mais moderna e refinada no tema escuro, para que o app tenha uma identidade visual coesa, profissional e agradável de usar.

## Contexto Técnico
O app já usa slate/indigo como base dark. Esta story **não adiciona toggle claro/escuro** — foca em elevar a qualidade visual do tema escuro existente com um design system consistente.

## Acceptance Criteria

### Design System
- [ ] Paleta de cores consolidada em `tailwind.config.ts` com tokens nomeados (brand, surface, muted, border, etc.)
- [ ] Tipografia refinada: hierarquia clara entre título, corpo, caption e label
- [ ] Espaçamento e padding consistentes entre componentes

### ChatWindow
- [ ] Header com glass effect sutil (`backdrop-blur`, borda inferior com opacidade)
- [ ] Background de mensagens com gradiente sutil ou textura discreta (sem distrair)
- [ ] Input area moderna: borda arredondada, foco com glow de accent color, ícones de ação (imagem, enviar) com hover states

### MessageBubble
- [ ] Bolhas próprias: gradiente indigo com bordas levemente arredondadas e sombra suave
- [ ] Bolhas de outros: surface elevada com contraste correto (legibilidade WCAG AA)
- [ ] Avatar/iniciais do remetente: círculo colorido gerado a partir do username (hash para cor)
- [ ] Timestamp discreto mas legível
- [ ] Reações com pill arredondado e hover state

### RoomList
- [ ] Sidebar com surface diferenciada (não apenas bg puro)
- [ ] Cards de sala com hover state e transição suave
- [ ] Badge de sala ativa com accent color
- [ ] Header com logo e username com avatar gerado por iniciais

### Modais (CreateRoomModal, LoginForm)
- [ ] Overlay com blur backdrop
- [ ] Modal com bordas arredondadas, sombra profunda, padding generoso
- [ ] Inputs com labels flutuantes ou design moderno consistente
- [ ] Botão primário com gradiente ou accent sólido + hover com lift

### Micro-interações
- [ ] Transições CSS (`transition-all duration-150`) nos elementos interativos
- [ ] Scroll customizado discreto (webkit-scrollbar estilizado)
- [ ] Estados de loading/skeleton onde há fetch assíncrono
