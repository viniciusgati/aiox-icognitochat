# Story 1.22 — Reações por Emoji

**Status:** Ready for Dev
**Epic:** 1 — IcognitoChat MVP
**Story:** 1.22
**Depende de:** 1.4

---

## Descrição

Como usuário, quero reagir a mensagens com emojis, para dar feedback rápido sem poluir o chat com respostas de texto.

---

## Critérios de Aceitação

- [ ] Hover/clique longo em mensagem exibe picker com 6 emojis fixos: 👍 ❤️ 😂 😮 🔥 👏
- [ ] Clicar num emoji envia `react-to-message` via Socket.io (toggle: segundo clique remove)
- [ ] Servidor faz broadcast de `reaction-updated` com contagens atualizadas para a sala
- [ ] MessageBubble exibe contagens de reações abaixo do conteúdo
- [ ] Reações são efêmeras (in-memory apenas, não persistidas no banco — consistente com E2E)
- [ ] Reação do próprio usuário aparece destacada

---

## Tarefas

- [ ] Adicionar `reactions: Record<string, Set<string>>` em memória no `server.ts` (messageId → emoji → Set<socketId>)
- [ ] Adicionar evento `react-to-message` no server com broadcast `reaction-updated`
- [ ] Atualizar `Message` interface com `reactions?: Record<string, number>`
- [ ] Adicionar listener `reaction-updated` no `socket-client.ts`
- [ ] Adicionar função `sendReaction(messageId, emoji)` no `socket-client.ts`
- [ ] Atualizar `MessageBubble.tsx` com picker e exibição de contagens
- [ ] Passar `sendReaction` do ChatWindow para MessageBubble
