# Story 1.32 — Push Notifications (Admin → Usuário)

## Status: Ready for Review

## Story
Como administrador, quero enviar push notifications para usuários específicos ou para todos, usando mensagens pré-configuradas ou personalizadas, para que eu possa avisar sobre atendimentos, chegadas ou qualquer evento relevante — mesmo com o app fechado no device do usuário.

## Contexto Técnico
O Service Worker já existe (story 1.6). Push notifications usam a Web Push API com autenticação VAPID. O servidor nunca vê o conteúdo das mensagens em texto claro — apenas assina e envia o payload via endpoint do browser.

## Acceptance Criteria

### Subscrição (Client)
- [ ] Ao entrar no chat, app solicita permissão de notificação ao usuário (`Notification.requestPermission()`)
- [ ] Se concedida, gera subscription via `PushManager.subscribe()` com a VAPID public key
- [ ] Subscription salva no servidor via `POST /api/push/subscribe`
- [ ] Permissão negada tratada silenciosamente — sem bloqueio de uso

### Service Worker
- [ ] Handler do evento `push` exibe a notificação com título, corpo e ícone do app
- [ ] Clique na notificação abre/foca o app (`clients.openWindow('/')`)

### API
- [ ] `POST /api/push/subscribe` — salva subscription (userId + endpoint + keys) no DB
- [ ] `POST /api/auth/admin/push/send` — envia notificação; protegido por auth admin + rate limit

### Admin UI (nova aba "Notificações" no dashboard)
- [ ] Lista de usuários com checkbox para selecionar destinatários (ou "Todos")
- [ ] Seletor de template pré-configurado:
  - "Olá {nome}, estou a caminho."
  - "Olá {nome}, falta 1 hora para o seu caso."
  - "Olá {nome}, seu atendimento começa em breve."
  - "Olá {nome}, por favor aguarde."
  - ✏️ Mensagem personalizada (campo livre)
- [ ] `{nome}` substituído pelo username do destinatário no envio
- [ ] Botão "Enviar" com feedback de sucesso/erro por destinatário
- [ ] Usuários sem subscription ativa exibem badge "sem push" (permissão não concedida)

### Infraestrutura
- [ ] Variáveis de ambiente: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`
- [ ] `.env.example` atualizado com as 3 variáveis
- [ ] `web-push` adicionado como dependência
