# Story 1.12 — Rate Limiting nas APIs de Autenticação

**Status:** Ready for Review
**Epic:** 1 — IcognitoChat MVP
**Story:** 1.12
**Depende de:** 1.2

---

## Descrição

Como administrador, quero que a API de login tenha proteção contra força bruta, para que contas de usuários não sejam comprometidas por tentativas automatizadas de adivinhação de senha.

---

## Contexto Técnico

`POST /api/auth/login` e `POST /api/auth/admin/users` não têm qualquer limitação de taxa. Com o banco persistindo via Railway Volume (Story 1.10), credenciais sobrevivem entre deploys — tornando brute force uma ameaça real.

Solução: Map em memória no servidor com janela deslizante por IP. Adequado para single-instance Railway. Se escalar para múltiplas instâncias, migrar para Redis.

- **Login:** 5 falhas por IP em 60s → HTTP 429
- **Admin:** 3 falhas por IP em 60s → HTTP 429
- Tentativas bem-sucedidas resetam o contador

---

## Critérios de Aceitação

- [ ] `POST /api/auth/login`: máximo 5 falhas por IP em 60 segundos → retorna `429` com header `Retry-After`
- [ ] `POST /api/auth/admin/users`: máximo 3 falhas por IP em 60 segundos → retorna `429`
- [ ] Login bem-sucedido reseta o contador do IP
- [ ] Resposta 429 inclui `{ error: 'Too many attempts', retryAfter: N }` no body
- [ ] IP extraído do header `x-forwarded-for` (Railway usa proxy reverso)
- [ ] Login normal dentro do limite não tem latência perceptível

## Notas de Implementação

```typescript
// src/lib/rate-limit.ts
export class RateLimiter {
  private store = new Map<string, { failures: number; windowStart: number }>()

  check(ip: string, limit: number, windowMs: number): { allowed: boolean; retryAfter: number } {
    const now = Date.now()
    const entry = this.store.get(ip)
    if (!entry || now - entry.windowStart > windowMs) {
      this.store.set(ip, { failures: 0, windowStart: now })
      return { allowed: true, retryAfter: 0 }
    }
    if (entry.failures >= limit) {
      return { allowed: false, retryAfter: Math.ceil((entry.windowStart + windowMs - now) / 1000) }
    }
    return { allowed: true, retryAfter: 0 }
  }

  recordFailure(ip: string): void { this.store.get(ip) && this.store.get(ip)!.failures++ }
  onSuccess(ip: string): void { this.store.delete(ip) }
}
```
