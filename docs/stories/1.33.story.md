# Story 1.33 — Painel de Privacidade (Auto-destruir + Apagar Tudo)

## Status: Ready for Dev

## Story
Como usuário, quero um painel de privacidade no meu device onde posso configurar auto-destruição local de mensagens e apagar completamente todos os meus dados locais com um botão de emergência, para ter controle total sobre o que fica armazenado no meu aparelho.

## Contexto Técnico
100% client-side — nenhuma mudança no servidor. Reutiliza o padrão de `localStorage` estabelecido na story 1.30. O "apagar tudo" encadeia: logout (API), clear localStorage, clear Service Worker cache, disconnect socket, redirect para "/".

## Acceptance Criteria

### Auto-destruir mensagens (local)
- [ ] Opções de TTL local: `off`, `30s`, `1m`, `5m`, `10m`, `30m`, `1h`
- [ ] Preferência salva em `localStorage` e restaurada no mount
- [ ] Mensagens desaparecem do estado React após o TTL — calculado a partir do `timestamp` da mensagem
- [ ] Se a sala já tiver TTL (story 1.25), o mais restritivo entre os dois vence localmente
- [ ] Aplica-se a mensagens próprias e de outros

### Apagar tudo do device
- [ ] Botão vermelho "Apagar tudo" bem visível no painel
- [ ] Primeiro clique abre modal de alerta listando o que será apagado:
  - Sessão ativa (logout)
  - Preferências salvas (localStorage)
  - Cache do app (Service Worker)
  - Histórico de mensagens em memória
- [ ] Confirmação: usuário digita `"APAGAR"` para liberar o botão final
- [ ] Sequência de limpeza: `socket.disconnect()` → `POST /api/auth/logout` → `localStorage.clear()` → `caches.keys/delete()` → `window.location.replace('/')`
- [ ] Após redirect, app abre limpo na tela de login

### UI
- [ ] Ícone 🛡️ no header do ChatWindow abre o painel de privacidade
- [ ] Painel organizado em duas seções: "Auto-destruir mensagens" e "Dados do device"
- [ ] Design consistente com painel de notificações (story 1.30)
