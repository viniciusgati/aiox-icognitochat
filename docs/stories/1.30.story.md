# Story 1.30 — Notificações de Mensagem com Seleção de Som

## Status: Done

## Story
Como usuário, quero ser notificado com um som ao receber mensagens enquanto a janela não está em foco, e poder escolher o som de notificação entre algumas opções, para que eu não perca mensagens importantes.

## Acceptance Criteria
- [ ] Som toca ao receber mensagem apenas quando a janela/aba não está em foco
- [ ] Sem som para mensagens próprias
- [ ] Painel de configurações acessível por ícone (🔔) na barra superior do ChatWindow
- [ ] 5 opções de som: `none` (silencioso), `bubble`, `ping`, `chime`, `pop`
- [ ] Preview do som ao clicar em cada opção no painel
- [ ] Toggle para ativar/desativar notificações sonoras (padrão: ativo com `bubble`)
- [ ] Preferências salvas em `localStorage` e restauradas no mount
- [ ] Assets de som em `/public/sounds/` como arquivos `.mp3` estáticos

## Tasks
- [x] Sons implementados via Web Audio API (síntese no browser — sem arquivos MP3)
- [x] Criar `src/lib/notification-prefs.ts` — leitura/escrita de preferências no localStorage
- [x] Criar `src/components/NotificationSettings.tsx` — painel com selector de som + toggle
- [x] Atualizar `src/components/ChatWindow.tsx` — acionar som no `receive-message` quando `document.hidden`, ignorar mensagens próprias
