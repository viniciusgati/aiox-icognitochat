# Story 1.41 — Push Notifications para Mensagens de Chat (Janela sem Foco)

## Status: Ready for Review

## Story

Como usuário com notificações push ativadas, quero receber uma notificação do sistema operacional quando uma nova mensagem chegar em qualquer sala que eu esteja, desde que o aplicativo não esteja visível/focado, para que eu não perca mensagens mesmo com o app em segundo plano ou minimizado.

## Contexto Técnico

### Pré-requisito já aplicado

`worker/push-handler.js` foi renomeado para `worker/index.js` (fix da Story 1.41 parcial). O next-pwa v5.6.0 só compila `index.js` ou `index.ts` como entry point do custom worker — o arquivo anterior era ignorado silenciosamente e o `sw.js` gerado não continha nenhum listener de push.

### Situação atual

O app já possui:
- Infrastructure de push completa: VAPID keys, `push_subscriptions` table, `sendPushNotification()` em `src/lib/push.ts`
- Service worker com listeners `push` e `notificationclick` em `worker/index.js`
- Notificações push apenas para **admins** (salas `vendas-*`, contact-admin, envio manual)
- Para usuários normais: apenas badge de tab + som (só funciona com o browser aberto)

### O que falta implementar

**Quando uma mensagem chega numa sala**, o servidor deve:
1. Identificar os usuários conectados na sala (via `roomUsers.get(roomId)`)
2. Para cada socket presente, obter o `socket.data.userId` (já disponível via middleware iron-session em `server.ts:67`)
3. Consultar `push_subscriptions` para esses user_ids
4. Enviar push para todos **exceto o remetente**

**No service worker**, o listener de push deve:
- Verificar se alguma janela do app está visível antes de exibir a notificação
- Se visível: suprimir (o app já trata via socket.io + som + badge)
- Se não visível: exibir notificação normalmente

### Pontos de atenção

- Mensagens são **E2E cifradas** — o servidor nunca vê o conteúdo. A notificação push deve conter apenas `"Nova mensagem de {username}"` sem o texto da mensagem
- Salas efêmeras e persistentes devem ser tratadas igualmente (roomUsers cobre ambas)
- Usuários **desconectados** (offline) não estão em `roomUsers` — push para offline está fora do escopo desta story
- Best-effort: falhas no envio de push não devem impactar o relay da mensagem

### Arquivos relevantes

- `server.ts` — adicionar lógica de push no handler `send-message` (linha ~300)
- `worker/index.js` — atualizar listener `push` para verificar visibilidade antes de exibir
- `src/lib/push.ts` — já pronto, sem alteração necessária

## Acceptance Criteria

- [ ] Ao receber uma mensagem numa sala, o servidor envia push para todos os participantes conectados com subscription ativa, exceto o remetente
- [ ] A notificação exibe: título `"IcognitoChat"`, corpo `"Nova mensagem de {username}"`
- [ ] Se o app estiver visível em alguma janela/aba, a notificação **não** é exibida (service worker suprime)
- [ ] Se o app estiver em segundo plano, minimizado ou a aba não estiver visível, a notificação **é exibida**
- [ ] Clicar na notificação abre/foca o app
- [ ] Falhas no envio de push não afetam o relay da mensagem (best-effort, try/catch)
- [ ] Funciona em desktop (browser) e mobile (PWA instalado)

## Dev Notes

### Coleta de userId dos participantes da sala (server.ts)

```typescript
// Após socket.to(data.roomId).emit('receive-message', ...)
try {
  const { sendPushNotification } = await import('@/lib/push')
  const socketsInRoom = await io.in(data.roomId).fetchSockets()
  const recipientUserIds = socketsInRoom
    .map(s => s.data.userId as number | undefined)
    .filter((id): id is number => !!id && id !== socket.data.userId)

  if (recipientUserIds.length > 0) {
    const placeholders = recipientUserIds.map(() => '?').join(',')
    const subs = db.prepare(
      `SELECT endpoint, p256dh, auth FROM push_subscriptions WHERE user_id IN (${placeholders})`
    ).all(...recipientUserIds) as { endpoint: string; p256dh: string; auth: string }[]

    for (const sub of subs) {
      sendPushNotification(sub, {
        title: 'IcognitoChat',
        body: `Nova mensagem de ${data.username}`,
      }).catch(() => {/* best-effort */})
    }
  }
} catch {
  // Push é opcional — não impacta o relay
}
```

### Service worker (worker/index.js) — suprimir se visível

```javascript
self.addEventListener('push', (event) => {
  if (!event.data) return

  let payload
  try { payload = event.data.json() }
  catch { payload = { title: 'IcognitoChat', body: event.data.text() } }

  const title = payload.title ?? 'IcognitoChat'
  const options = {
    body: payload.body ?? '',
    icon: payload.icon ?? '/icon-192.png',
    badge: '/icon-192.png',
    data: { url: '/' },
  }

  event.waitUntil(
    clients.matchAll({ type: 'window', includeUncontrolled: true }).then((clientList) => {
      const appVisible = clientList.some(c => c.visibilityState === 'visible')
      if (appVisible) return // app em foco — não exibir
      return self.registration.showNotification(title, options)
    })
  )
})
```
