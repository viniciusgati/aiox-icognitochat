# Story 1.39 — Correção do Modo Suporte: Remover Restrição de Salas para Usuários

## Status: Ready for Review

## Story

Como usuário, quero poder acessar qualquer sala (incluindo salas criadas pelo admin e compartilhadas comigo) sem ser redirecionado, para que possa conversar livremente com outros usuários.

Como admin, quero que o controle de "contato direto comigo" seja independente da capacidade dos usuários de conversar entre si, para que eu possa configurar apenas o canal de suporte direto sem bloquear o chat normal.

## Contexto Técnico

### O Problema

O setting `admin_only_chat` implementado nas Stories anteriores tem um comportamento incorreto: quando ativado, redireciona qualquer usuário não-admin que tente acessar qualquer sala que não seja `general` ou `vendas-*` para `/chat/general?reason=restricted`.

Isso quebra o fluxo onde o admin cria uma sala e compartilha o link com um usuário — ao acessar o link, o usuário é barrado e redirecionado.

**Comportamento atual (ERRADO):**
- `admin_only_chat = '1'` → Usuário tenta entrar em `/chat/minha-sala` → redirecionado para `/chat/general`
- Admin compartilha sala com usuário → usuário não consegue entrar

**Comportamento correto:**
- Usuários podem criar salas e conversar livremente (sem nenhuma restrição de acesso a salas não-privadas)
- `allow_contact_admin` controla APENAS o botão "💬 Suporte" (canal de vendas direto com o admin)
- Não existe conceito de "modo suporte que bloqueia salas" — esse conceito nunca foi correto
