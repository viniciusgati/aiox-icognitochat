# Story 1.7 — Sala Rápida Efêmera

**Status:** Ready for Review
**Epic:** 1 — IcognitoChat MVP
**Story:** 1.7
**Depende de:** 1.6

---

## Descrição

Como usuário, quero criar uma sala rápida anônima, copiar o link e mandar para alguém, conversar com criptografia E2E, e quando os dois desconectarem a sala desaparecer automaticamente — sem rastros.

---

## Critérios de Aceitação

- [x] Modal "Nova Sala" tem toggle "Sala Rápida (efêmera)"
- [x] Sala efêmera recebe slug aleatório (ex: `xk9m-2p7q`) — não derivado do nome
- [x] Salas efêmeras NÃO aparecem na lista do hub `/chat`
- [x] Ao entrar numa sala efêmera, ChatWindow exibe banner com link compartilhável + botão "Copiar Link"
- [x] Banner mostra aviso: "Sala efêmera — apagada quando todos saírem"
- [x] Quando o último usuário desconecta de uma sala efêmera, o servidor a deleta do banco
- [x] Acessar link de sala efêmera já deletada redireciona para `/chat`
- [x] Chat E2E funciona normalmente (herda Story 1.4)

### Completion Notes

- Migration `is_ephemeral INTEGER NOT NULL DEFAULT 0` adicionada via `ALTER TABLE` com try/catch (idempotente)
- `deleteRoom(slug)` exportada de `db.ts` e usada pelo servidor quando sala efêmera fica vazia
- `generateEphemeralSlug()` usa `crypto.randomBytes(8)` para slug `xxxx-xxxx` — name=slug para satisfazer constraint UNIQUE
- GET `/api/rooms` filtra `WHERE is_ephemeral = 0` — salas efêmeras invisíveis no hub
- `server.ts` mantém `ephemeralRooms: Set<string>` e `handleRoomEmpty()` chamado em `leave-room` e `disconnect`
- `useSocket` agora aceita `ephemeral` como 3º parâmetro e passa no `join-room` emit
- `ChatWindow` recebe `isEphemeral` prop: exibe banner indigo com URL + botão "Copiar", badge "efêmera" no header, aviso âmbar
- Correção lint: `ephemeral` adicionado ao array de deps do `useEffect` em `socket-client.ts`
- `npm run lint`, `npm run typecheck`, `npm run build` — todos passaram sem erros
