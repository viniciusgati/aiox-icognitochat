# Story 1.3 — Hub de Salas + Chat Geral

**Status:** Done
**Epic:** 1 — IcognitoChat MVP
**Story:** 1.3
**Depende de:** 1.2

---

## Descrição

Como usuário autenticado, quero ver uma lista de salas disponíveis, entrar no chat geral e poder criar novas salas, para que eu possa conversar com meus amigos de forma organizada.

---

## Critérios de Aceitação

- [ ] Página `/chat` exibe: cabeçalho com username logado + botão logout, sala "Geral" sempre visível no topo, lista de salas criadas pelos usuários
- [ ] Botão "Nova Sala" abre modal com campo para nome da sala
- [ ] Qualquer usuário autenticado pode criar uma sala
- [ ] Criação de sala: nome único, slug gerado automaticamente (ex: "Minha Sala" → `minha-sala`)
- [ ] Clicar em uma sala navega para `/chat/[roomId]`
- [ ] Sala "Geral" (`general`) é criada automaticamente no seed do banco
- [ ] Rota `GET /api/rooms` retorna lista de salas
- [ ] Rota `POST /api/rooms` cria nova sala (autenticado)
- [ ] Layout responsivo — funciona bem em mobile (PWA)
