# Story 1.5 — Limpeza Segura de Dados ao Fechar

**Status:** Done
**Epic:** 1 — IcognitoChat MVP
**Story:** 1.5
**Depende de:** 1.4

---

## Descrição

Como usuário preocupado com privacidade, quero que ao fechar o browser/aba toda evidência das minhas mensagens seja apagada da memória do browser, e que no servidor as mensagens sejam descartadas da sessão, para que não seja possível recuperar o histórico após o fechamento.

---

## Critérios de Aceitação

- [ ] `beforeunload` event: limpa a chave criptográfica da memória (`CryptoKey` nullificada)
- [ ] Mensagens em memória React state são zeradas antes de desmontar componente
- [ ] Session cookie é destruído ao logout explícito
- [ ] Servidor: ao desconexão WebSocket, remove usuário da lista de presença
- [ ] Servidor: processo SIGTERM/SIGINT sobrescreve arquivo SQLite com zeros antes de encerrar
- [ ] Nenhuma mensagem é salva em `localStorage`, `sessionStorage` ou `IndexedDB`
- [ ] Console.log de mensagens em plain text desativado em produção (`NODE_ENV=production`)

## Notas de Implementação

```typescript
// Sobrescrever arquivo SQLite antes de fechar servidor
function zeroizeDb(dbPath: string) {
  const size = fs.statSync(dbPath).size;
  const zeros = Buffer.alloc(size, 0);
  fs.writeFileSync(dbPath, zeros);
  fs.unlinkSync(dbPath);
}
```

```typescript
// Limpar chave criptográfica da memória
// CryptoKey é um objeto opaco — não podemos zerar bytes diretamente
// A melhor abordagem é: anular referência + forçar GC (limitado em JS)
function clearCryptoKey(keyRef: { current: CryptoKey | null }) {
  keyRef.current = null;
}
```

**Limitação conhecida:** JavaScript não permite acesso direto à memória heap. O "zeroize" de mensagens é best-effort — sobrescrever o array com strings vazias antes do GC diminui a janela de exposição mas não é garantia absoluta. Documentar isso na UI se necessário.
