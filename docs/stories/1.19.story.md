# Story 1.19 — Logs Estruturados com Pino

**Status:** Ready
**Epic:** 1 — IcognitoChat MVP
**Story:** 1.19
**Depende de:** 1.1

---

## Descrição

Como operador, quero que os logs do servidor sejam estruturados em JSON com níveis e campos padronizados, para que eu possa filtrar e depurar problemas em produção no Railway sem precisar analisar strings de texto livre.

---

## Contexto Técnico

Atualmente o servidor usa `console.log` e `console.error` com strings livres. Isso é legível em dev mas impossível de filtrar/indexar em produção. O Railway exibe logs em plain text — com pino, é possível usar `pino-pretty` em dev e JSON em produção.

Pino foi escolhido por ser o logger mais rápido para Node.js, com overhead mínimo e integração nativa com Next.js.

---

## Critérios de Aceitação

- [ ] `pino` instalado como dependência de produção
- [ ] `pino-pretty` instalado como devDependency (formatação legível em dev)
- [ ] Logger singleton em `src/lib/logger.ts` exportado para uso em todo o projeto
- [ ] Em `NODE_ENV=production`: saída JSON (`{ level, time, msg, ...fields }`)
- [ ] Em `NODE_ENV=development`: saída colorida via `pino-pretty`
- [ ] `server.ts` usa o logger em vez de `console.log` nos eventos principais: startup, shutdown, Socket.io connections, erros
- [ ] Campos obrigatórios em logs de request: `{ msg, userId?, roomId?, socketId? }`
- [ ] `console.log` de debug (`if (dev)`) substituídos pelo logger com `logger.debug()`

---

## Tarefas

- [ ] Instalar dependências:
  - `npm install pino`
  - `npm install -D pino-pretty`

- [ ] Criar `src/lib/logger.ts`:
  - Exportar instância pino configurada por `NODE_ENV`

  - Nível padrão: `info` (prod), `debug` (dev)

- [ ] Atualizar `server.ts`:
  - Substituir `console.log` por `logger.info()` / `logger.debug()` / `logger.error()`
  - Manter campos contextuais: `{ socketId, username, roomId }` nos eventos Socket.io

- [ ] Atualizar `.env.example`:
  - Adicionar `LOG_LEVEL=info`

## Notas de Implementação

```typescript
// src/lib/logger.ts
import pino from 'pino'

const logger = pino({
  level: process.env.LOG_LEVEL ?? (process.env.NODE_ENV === 'production' ? 'info' : 'debug'),
  ...(process.env.NODE_ENV !== 'production' && {
    transport: { target: 'pino-pretty', options: { colorize: true, ignore: 'pid,hostname' } },
  }),
})

export default logger
```
