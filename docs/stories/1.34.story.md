# Story 1.34 — Watermark Invisível em Imagens do Chat

## Status: Ready for Dev

## Story
Como administrador, quero que todas as imagens exibidas no chat contenham um watermark invisível com a identidade do usuário, para que eu possa rastrear a origem de vazamentos caso uma imagem seja compartilhada externamente.

## Contexto Técnico
Implementação 100% client-side via canvas rendering. Ao exibir uma imagem no `MessageBubble` e no `ImageLightbox`, a imagem é renderizada em um `<canvas>` com um overlay de texto (username + roomId + timestamp) em opacidade extremamente baixa (~3-5%). O `<img>` original é substituído pelo canvas. O watermark é legível por ferramentas de análise de imagem mas imperceptível a olho nu.

## Acceptance Criteria

### Renderização via Canvas
- [ ] Em `MessageBubble`, imagens são renderizadas via `<canvas>` ao invés de `<img>` direto
- [ ] Em `ImageLightbox`, a imagem expandida também usa canvas com watermark
- [ ] O canvas mantém as mesmas dimensões e aspect ratio da imagem original
- [ ] A imagem permanece visualmente idêntica (watermark imperceptível a olho nu)

### Conteúdo do Watermark
- [ ] Watermark contém: `username | roomId | timestamp (ISO)` repetido em grid sobre toda a imagem
- [ ] Texto em fonte pequena (10-12px), opacidade 0.04 (4%), cor branca com shadow preta
- [ ] Repetição em padrão diagonal cobre toda a superfície da imagem
- [ ] O padrão é suficientemente denso para sobreviver a crop parcial

### Compatibilidade e Performance
- [ ] Canvas rendering não quebra o layout existente de imagens
- [ ] Não impacta visualmente o lightbox (Story 1.29)
- [ ] Funciona com imagens de qualquer tamanho e proporção
- [ ] Sem dependências novas (usa Canvas API nativa do browser)

### Fallback
- [ ] Se o canvas não for suportado (improvável), exibir `<img>` original sem watermark
- [ ] Nenhum erro no console em caso de falha de carregamento da imagem

## Dev Notes

### Canvas Watermark Pattern
```typescript
function drawWatermark(ctx: CanvasRenderingContext2D, width: number, height: number, label: string) {
  ctx.save()
  ctx.globalAlpha = 0.04
  ctx.fillStyle = 'white'
  ctx.font = '11px monospace'
  ctx.shadowColor = 'black'
  ctx.shadowBlur = 1
  // Rotacionar -30 graus e repetir em grid
  ctx.translate(width / 2, height / 2)
  ctx.rotate(-Math.PI / 6)
  const step = 120
  for (let x = -width; x < width * 2; x += step) {
    for (let y = -height; y < height * 2; y += step) {
      ctx.fillText(label, x, y)
    }
  }
  ctx.restore()
}
```
